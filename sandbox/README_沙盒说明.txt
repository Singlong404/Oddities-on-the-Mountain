山间怪奇百货｜v6 独立沙盒 0.6.1
作者：AA_建筑设计沈工 / Singlong404
主页：https://singlong404.itch.io/

这是从 2026-11-12 的 v6 备份复制出来的独立项目。
用途：尝试不同店铺布局、操作动线和客流组合，保留 v6 清楚的方块灰盒风格。
它不是当前最终版本的回滚，不包含最终版的剧情、立绘、森林布景或新角色模型。
原 v6 备份与最终版本项目均不用于本沙盒开发。

【开始】
Unity 版本：6000.6.5f1。
打开 Assets/_Project/Scenes/Rush_SingleFloor.unity 后运行。
Windows：解压完整文件夹，运行 OdditiesSandboxV6.exe；exe 不能单独移动。
Web：通过 HTTP/HTTPS 打开 index.html，不要双击 file:// 页面。

【沙盒循环】
从空场地开始，初始建设金 2000，最多铺 160㎡。
地坪 → 门路 → 设备 → 亲自营业 → 热区复盘 → 保留布局继续调整。
不再要求四轮达到指定营业额，不出现强制通关终点。
营业收入继续累积；每次试营业结束保留布局，不自动切换客流。
准备时可自由切换四档客流：原货、打包山风、热饮雨势、混合高峰。
设备全部开放，取货架和交付台各最多 4 个，打包台和热饮台各最多 3 个。
开门前仍需放好对应客流需要的设备，留出真实可达的操作面及顾客通路。
可开启免费建造；这一选项用于布局实验，不作为经济挑战成绩。
重新开场需要点击两次，清空当前会话；既有手动存档保留。

【操作】
第一步拖画地坪、用途或拆除；留白地坪可作为通道。
第二步点墙调整门；保留 v6 自动补门，也可手动微调。
前两步 V 或画面按钮切换平面/轴测；中键平移，滚轮缩放。
第三步 WASD 移动、左键放置、R 旋转、滚轮切设备、E 搬起、X 回收。
营业时 WASD 移动、Shift 快走；E 取货/交付，按住 E 加工/清理。
E 取三份原货，Shift+E 取一份。加工成品可暂放回对应加工台。
Esc 打开帮助/暂停；准备期搬动家具时先取消搬动。
Ctrl+Z 撤销建造，Ctrl+S 保存；右上角“存”“读”提供鼠标入口。
暂停菜单可提前结束试营业，统计实际已到店顾客。

【本次修复与完善】
1. 拆地坪自动移除相交家具，付费建造时一并退款；撤销完整恢复。
2. 清理不再存在的墙上的旧门数据。
3. 读档重置建造工具与旋转，拒绝非法步骤、角色坐标、设备编号及异常现场。
4. 存档保留备份回退；营业中读档默认暂停，防止读档后立即漏单。
5. Web 使用 IndexedDB 持久化同步及兼容写入方式；内置中文字体。
6. 相机平移加快，限制实际目标，避免鼠标长距离拖动后镜头迟迟回不来。
7. 建造网格、门洞与操作侧标记更清楚；货架商品随库存显示。
8. 沙盒存档、产品名和发布目录与最终版隔离。

【存档】
Windows：%USERPROFILE%/AppData/LocalLow/Singlong404/Oddities Sandbox v6/SandboxV6
Web：当前网站源下的浏览器 IndexedDB；需要使用相同地址和正常浏览模式。
手动存档 manual.json，自动存档 auto.json；同名 .bak 用于损坏恢复。
网页保存后稍等再关闭。清除站点数据或使用隐私浏览会影响保留。
不自动导入或覆盖最终版和旧 v6 存档。

【架构与修改入口】
RushRules.asset：客人数、服务时长、价格、移动速度、沙盒面积、字体。
RushGame.cs：输入、三个建设步骤、放置与拆除、阶段切换。
RushGame.Sandbox.cs：客流切换、免费建造、继续试营业、重开、附加存档校验。
RushGame.World.cs：方块场景、墙门、NavMesh、相机、热区。
RushGame.Business.cs：队列、手动交付、加工、补货、山风和雨势。
RushGame.UI.cs：运行时生成的 UI、订单卡、提示、复盘。
RushGame.Save.cs / SandboxPersistence.cs：原子保存、备份恢复、网页落盘。
RushGame.Verification.cs / SandboxChecks.cs：开发验证，不进入普通发布包。
Editor/SandboxBuild.cs：独立场景配置、自动验证、Windows/Web 打包。
场景仍沿用 v6 运行时生成方式，运行后 Hierarchy 中可查看各对象分组。
旧 Demo、Graybox 脚本用于保留依赖；不要运行旧的 DemoSetup/RushSetup 覆盖沙盒配置。
